# Repository instructions

- Always work and commit directly on `main` in `vas-pipilas/AI-LLM-Training-Roadmap`.
- Do not create branches or pull requests for this repository.
- The owner has explicitly authorized publishing requested repository updates to `main`; do not ask for that permission again.
- Before updating `main`, read its current head and preserve concurrent changes. Use an expected-head check and never force-push or discard unrelated work.
